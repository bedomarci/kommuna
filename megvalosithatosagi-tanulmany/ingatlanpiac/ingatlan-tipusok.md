# Ingatlantípusok összehasonlítása

**Státusz:** ⬜ Még nem kitöltött

## A fájl célja

Ez a dokumentum összehasonlítja azokat az ingatlantípusokat, amelyek alkalmasak lehetnek egy kommuna céljaira. Célja, hogy a csoport a költségek, előnyök és hátrányok ismeretében tudjon dönteni arról, milyen típusú ingatlant keressen — üres telektől a volt mezőgazdasági majorig.

---

## 1. Üres telek (beépítetlen)

Épület nélküli, beépítetlen mezőgazdasági terület.

| Szempont | Részletek |
|----------|-----------|
| Előnyök | Teljesen saját tervezés, minden a csoport igényei szerint alakítható. Nincs kompromisszum meglévő épületekkel. |
| | ⬜ |
| | ⬜ |
| Hátrányok | Drága építkezés, hosszú átfutási idő. Mindent a nulláról kell megteremteni. |
| | ⬜ |
| | ⬜ |
| Becsült költség | ⬜ Ft (telek + építkezés) |
| Építési idő | ⬜ hónap / év |
| Elérhetőség | ⬜ (mennyire gyakori, mennyi hirdetés van?) |

---

## 2. Hagyományos tanya felújítandó épülettel

Meglévő lakó- és/vagy gazdasági épületekkel rendelkező tanya, amely felújításra szorul.

| Szempont | Részletek |
|----------|-----------|
| Előnyök | Olcsóbb, mint az új építés. Van kiindulási alap, gyorsabban beköltözhető. Meglévő közművek esélye. |
| | ⬜ |
| | ⬜ |
| Hátrányok | Felújítás költsége magas lehet. Rejtett hibák, meglepetések. Kompromisszum a meglévő elrendezéssel. |
| | ⬜ |
| | ⬜ |
| Becsült költség (vásárlás + felújítás) | ⬜ Ft |
| Felújítási idő | ⬜ hónap / év |
| Mire figyeljünk? | ⬜ |

---

## 3. Régi mezőgazdasági major / telephely

Egykori állattartó telep, gépszín, terménytároló — nagy terület, meglévő épületállomány.

| Szempont | Részletek |
|----------|-----------|
| Előnyök | Nagy terület, meglévő épületek (istállók, csűrök). Több épület = többféle funkcióra alakítható. |
| | ⬜ |
| | ⬜ |
| Hátrányok | Ipari mezőgazdasági jelleg — átépítés költséges. Esetleges környezeti szennyezés (talaj, talajvíz). Engedélyeztetés nehézkes lehet lakhatásra. |
| | ⬜ |
| | ⬜ |
| Becsült költség (vásárlás + átépítés) | ⬜ Ft |
| Átépítési idő | ⬜ hónap / év |
| Mire figyeljünk? | ⬜ |

## 4. Volt TSZ iroda / központ

Egykori termelőszövetkezeti iroda, központi épület, esetleg kiegészítő épületekkel.

| Szempont | Részletek |
|----------|-----------|
| Előnyök | Szilárd építésű, gyakran központi fekvésű. Irodák, közösségi terek már adottak. |
| | ⬜ |
| | ⬜ |
| Hátrányok | Nem mezőgazdasági lakhatásra tervezték. Átépítés lakássá költséges. Közművek kérdésesek. |
| | ⬜ |
| | ⬜ |
| Becsült költség (vásárlás + átépítés) | ⬜ Ft |
| Átépítési idő | ⬜ hónap / év |
| Mire figyeljünk? | ⬜ |

## 5. Erdei telek / tanya

Erdőterületen vagy erdő mellett fekvő ingatlan, erdőgazdálkodási lehetőséggel.

| Szempont | Részletek |
|----------|-----------|
| Előnyök | Természetközeli, vonzó környezet. Erdőgazdálkodás (tűzifa, faanyag). Erdei termékek (gomba, gyógynövény). |
| | ⬜ |
| | ⬜ |
| Hátrányok | Szigorú építési korlátozások (erdőtörvény). Vadkár a terményben. Az erdő művelési kötelezettséggel járhat. |
| | ⬜ |
| | ⬜ |
| Becsült költség (vásárlás + építés) | ⬜ Ft |
| Mire figyeljünk? | ⬜ |
