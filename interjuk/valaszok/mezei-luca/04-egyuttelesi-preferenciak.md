## 4.1 — Térigény és privát szféra

| Kérdés                                       | Válasz |
| -------------------------------------------- | ------ |
| Mekkora privát térre van szükséged? (szoba, lakrész) | |
| Mennyire fontos számodra a saját fürdőszoba / konyha? | |
| Hogyan viszonyulsz a közös terekhez?          |        |
| Van-e igényed saját kertre vagy kültéri térre? |        |

| Kérdés                                       | Válasz |
| -------------------------------------------- | ------ |
