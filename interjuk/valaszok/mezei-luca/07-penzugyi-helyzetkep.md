Ebben a dokumentumban Mezei Luca pénzügyi helyzetével, jövedelmével, kiadásaival és a kommunába való pénzügyi bekapcsolódásával kapcsolatos válaszok kerülnek rögzítésre.

## 7.1 — Jövedelmi helyzet

| Kérdés                                       | Válasz |
| -------------------------------------------- | ------ |
| Mi a fő jövedelemforrásod?                    |        |
| Mennyi a havi nettó jövedelmed? (becslés vagy sáv) | |
| Van-e egyéb, rendszeres bevételeid? (támogatás, bérleti díj, stb.) | |
| Mennyire stabil a jövedelmi helyzeted? (1–10)  |        |
