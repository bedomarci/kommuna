# Checklist – Első év

---

## Adminisztratív teendők

- [ ] Alapító okirat megírása és véglegesítése
- [ ] Jogi személy bejegyeztetése (bíróság / cégbíróság)
- [ ] Adószám igénylése
- [ ] Bankszámla nyitása a közösség nevére
- [ ] Székhely bejelentése
- [ ] Aláírási jogok és képviseleti szabályok rögzítése
- [ ] GDPR / adatkezelési szabályzat elkészítése
- [ ] Működési szabályzat / házirend első verziójának megírása

## Jogi teendők

- [ ] Jogi forma végleges kiválasztása (egyesület, szövetkezet, Kft., alapítvány)
- [ ] Tagsági szerződés sablon összeállítása
- [ ] Kilépési és belépési eljárásrend kidolgozása
- [ ] Ingatlan adásvételi / bérleti szerződés előkészítése
- [ ] Használati és tulajdoni megállapodás megkötése
- [ ] Biztosítások megkötése (ingatlan, felelősség, baleset)
- [ ] Szerződésminták gyűjteményének létrehozása (beszállítók, kivitelezők)
- [ ] Konfliktuskezelési protokoll írásba foglalása

## Pénzügyi teendők

- [ ] Éves költségvetés elkészítése
- [ ] Tagdíjak és hozzájárulások mértékének meghatározása
- [ ] Könyvelő keresése és szerződtetése
- [ ] Pénzügyi nyilvántartási rendszer felállítása (számlázás, bizonylatok)
- [ ] Pályázatfigyelés beindítása (önkormányzati, EU, alapítványi)
- [ ] Tartalékalap képzési szabály meghatározása
- [ ] Átláthatósági jelentés formátumának kidolgozása
- [ ] Első negyedéves pénzügyi beszámoló elkészítése

## Birtok keresése

- [ ] Keresési szempontok listájának összeállítása (méret, elhelyezkedés, közművek)
- [ ] Régiók és települések szűkítése
- [ ] Helyszíni szemlék lebonyolítása (min. 3-5 helyszín)
- [ ] Talaj- és vízvizsgálatok elvégeztetése
- [ ] Építési szabályozás és helyi rendeletek ellenőrzése
- [ ] Közmű bekötési lehetőségek felmérése
- [ ] Szomszédokkal és helyi közösséggel való ismerkedés
- [ ] Végleges döntés meghozatala (súlyozott döntési mátrix használata)

## Interjúk lebonyolítása

- [ ] Interjú kérdőívek összeállítása különböző szerepkörökre
- [ ] Jelentkezői adatbázis létrehozása és karbantartása
- [ ] Első körös beszélgetések lebonyolítása (online vagy személyesen)
- [ ] Próbaidőszak / közös hétvége megszervezése legalább 3 jelentkezővel
- [ ] Interjú összesítők kitöltése és archiválása
- [ ] Referenciák ellenőrzése
- [ ] Döntési folyamat dokumentálása

## Közösségépítés

- [ ] Közös értékek és jövőkép írásba foglalása
- [ ] Rendszeres heti online megbeszélés kialakítása
- [ ] Közös hétvége / csapatépítő megszervezése (min. negyedévente)
- [ ] Közösségi kommunikációs csatorna beállítása (Signal, Discord, stb.)
- [ ] Feladatkörök és felelősségi területek leosztása
- [ ] Elégedettségi felmérés lebonyolítása (6. hónap környékén)
- [ ] Közös naptár és teendőkezelő rendszer bevezetése

## Dokumentáció vezetése

- [ ] Döntések naplózási rendjének kialakítása
- [ ] Gyűlések jegyzőkönyveinek vezetése és tárolása
- [ ] Pénzügyi bizonylatok rendezett archívumának felállítása
- [ ] Szerződések és jogi dokumentumok rendezett tárolása
- [ ] Kockázati mátrix aktualizálása (negyedévente)
- [ ] Tagsági nyilvántartás naprakészen tartása
- [ ] Képes és videós dokumentáció a mérföldkövekről
- [ ] Év végi átfogó beszámoló elkészítése
